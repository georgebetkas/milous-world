Milou's World — Milestone 1 (Phaser + React)

1. Open your existing C:\Users\gamet\milou-world\web folder.
2. Stop the Vite server if needed (Ctrl+C).
3. Run: npm.cmd install phaser
4. Copy everything INSIDE this archive's src folder into your existing web\src folder.
   - Overwrite App.tsx, App.css, index.css.
   - Create game\MilouScene.ts.
   - Keep your existing main.tsx and project configuration.
5. Run: npm.cmd run dev
6. Open http://localhost:5173/ and click tiles.

This stage is a VISUAL, click-to-move prototype. There is no AI or saved memory yet.
